# 🧠 Customer Feedback Analyzer

A full-stack AI-powered feedback analytics dashboard built using React, FastAPI, MongoDB, and NLP.

## 🚀 Features

- Feedback collection
- Sentiment analysis (VADER)
- Keyword extraction
- Rating analytics
- CSV export reports
- Interactive dashboard

## 🛠 Tech Stack

Frontend:
- React
- Axios
- Recharts

Backend:
- FastAPI
- MongoDB
- VADER Sentiment Analysis
- Pandas

## 📊 How to Run

### Backend
cd backend  
python -m uvicorn main:app --reload  

### Frontend
cd frontend  
npm start
